# ТОБОТ: МИССИИ АЛЬТАИРА

Образовательная игра для ребёнка 4 лет: знакомство с цветами, голосовые задания и награды.
Работает в браузере без регистрации и без сервера.

## Структура

| Путь | Что там | Что менять |
|---|---|---|
| `index.html` | главный экран, сборка сцены и кнопок | экраны и кнопки |
| `js/tobot-character.js` | класс `TobotCharacter`: модель, анимации, рот, моргание | движение и мимику |
| `js/tobot-voice.js` | голос: выбор мужского русского голоса, 7 типов озвучки | тон, темп, выбор голоса |
| `js/tobot-lines.js` | все реплики Тобота по типам | текст реплик |
| `models/tobot.glb` | 3D-модель Тобота с 9 анимациями | заменить файлом с теми же именами клипов |
| `tools/build_tobot_glb.py` | генератор временной модели (без Blender) | только для пересборки временной модели |
| `missions/` | будущие миссии (цвета, викторина и т. д.) | добавлять новые миссии сюда |

## Запуск

Нужен локальный веб-сервер (открыть `index.html` двойным кликом нельзя: браузер не загрузит модель).

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Нужен интернет: three.js загружается с CDN.

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
Сайт откроется по адресу `https://<логин>.github.io/<имя-репозитория>/`.
На iPhone открывайте его в Safari и добавьте на экран «Домой».

## Обязательный контракт модели

Новый файл `models/tobot.glb` должен содержать клипы с именами:
`Idle, Greeting, Talking, Listening, Happy, Thinking, Sad, Victory, Pointing`.
Необязательные узлы по имени (если есть, оживляются): `Mouth, EyeL, EyeR, BrowL, BrowR, Antenna, Head`.
Проверить соответствие можно в консоли браузера: `console.warn` покажет недостающие клипы.

## Голоса

Приложение само выбирает мужской русский голос и запоминает выбор на устройстве.
Если его нет, на экране будет подсказка, как установить голос (iPhone, Android, Windows).

## Добавление миссий

Миссии будут в папке `missions/`. Каждая миссия — отдельный файл, например `missions/colors-1-red.json`.
Формат будет согласован на этапе модуля «Учить цвета».

## Приватность

Прогресс хранится только в браузере устройства (localStorage). Аудио с микрофона и данные ребёнка
никуда не отправляются.

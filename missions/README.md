# Игры и миссии

Реестр — `js/games.js`. Чтобы добавить игру: модуль `js/<имя>.js`, строка в `GAMES`, тексты в `js/game-text.js` (ru и kk).
«Начать приключение» проводит по играм по очереди (`ADVENTURE`), «Играть» открывает меню. Сложность растёт с числом пройденных раз.

| Игра | Файл | Суть |
|---|---|---|
| Цвета | `mission-colors.js` | «Найди красное яблоко!», цветов 4 → 8, всегда 4 варианта; красный, зелёный и коричневый выпадают чаще; без повторов подряд |
| Считаем | `choice-games.js` | «Сколько яблок?», числа до 3 → 9 |
| Фигуры | `choice-games.js` | круг, квадрат, треугольник, звезда, сердце |
| Кто как говорит | `choice-games.js` | «Кто говорит «мяу»?» |
| Найди лишнего | `choice-games.js` | три предмета одной группы и один чужой |
| Найди пару | `memory-game.js` | 2 → 3 → 4 пары карточек |
| Шарики | `balloon-game.js` | лопнуть 5 шариков нужного цвета |

Общее: подсказка (пульсация) после двух промахов или паузы, звуки и конфетти (`fx.js`), реплики Тобота из `content/phrases.json`.
Казахские тексты написаны не носителем, их нужно проверить.

## Запланировано
- Распознавание речи («скажи цвет»), нужен микрофон по нажатию.
- «Собери ракету» (раскрасить части ракеты), размер (большой/маленький), форма и цвет вместе.
